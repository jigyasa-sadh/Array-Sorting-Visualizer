 Array Sorting Visualizer

A modern web-based interactive **Sorting Visualizer** built using **HTML, CSS, and JavaScript**. This project helps users visualize how different sorting algorithms work step-by-step with dynamic bars and live values.

---

## ✨ Features
- **Algorithm Selection**: Choose from 7 popular sorting algorithms:
  - Bubble Sort
  - Insertion Sort
  - Selection Sort
  - Merge Sort
  - Quick Sort
  - Shell Sort
  - Radix Sort
- **Interactive UI**: Clean, modern dark-mode layout with a gradient sorting button and vertical visualizer bars.
- **Live Numbers**: Values are displayed directly on top of the bars and update in real-time during sorting.
- **Complexity Reference**: Automatically displays the **Time Complexity** and **Space Complexity** for the selected algorithm.

---

## 🛠️ Technologies Used
- **HTML5**: For structuring the web application interface.
- **CSS3**: For styling, modern layout, and custom animations.
- **JavaScript (ES6+)**: For implementing sorting logic, animations (`async/await`), and DOM manipulation.
